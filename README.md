Neon Coast is an original open-city action game that runs entirely in the browser — vanilla JS and Canvas, zero external assets, fully offline. Cruise a palm-lined coastal city on foot or behind the wheel, work through a finishable 6-mission story campaign with escalating wanted stars and police pursuits, and take the final run across the city to the pier. Full touch controls (virtual joystick + buttons) sit alongside keyboard and mouse, the minimap keeps the whole coast in view, and every screenshot scene is deterministic from its seed.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a browser
```
